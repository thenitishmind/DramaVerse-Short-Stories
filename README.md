# DramaVerse Short Stories

Short Stories. Big Emotions. Epic Gaming.

DramaVerse Short Stories is a web project featuring mini dramas, anime-inspired stories, romance, fantasy, and epic gaming content from Gurugram.

Repository: [DramaVerse-Short-Stories](https://github.com/thenitishmind/DramaVerse-Short-Stories)

## Project Structure

- `index.html` — Main HTML page
- `app.js` — JavaScript functionality
- `styles.css` — Styling
- `assets/` — Images and other static assets
